# نور الهدى — مشروع أندرويد تجريبي

مشروع بداية لتطبيق أندرويد باللغة العربية بألوان أخضر وذهبي.

## الموجود في هذه النسخة
- شاشة رئيسية وأقسام التطبيق.
- سبحة إلكترونية تعمل محلياً.
- أذكار مختارة مبدئية.
- حديث نبوي مع مصدره.
- صفحات أولية للقرآن ومواقيت الصلاة والقبلة.

## تنبيه مهم
هذه نسخة أولية وليست تطبيقاً إسلامياً مكتملاً أو APK جاهزاً. أقسام القرآن الكامل ومواقيت الصلاة الدقيقة واتجاه القبلة ما زالت تحتاج إلى تنفيذ ومراجعة واختبار. لا تعتمد على هذه النسخة كمصدر مكتمل للمحتوى الديني.

## بناء APK من الموبايل باستخدام GitHub Actions
1. أنشئ مستودعاً جديداً على GitHub من المتصفح.
2. ارفع جميع ملفات هذا المشروع إلى المستودع، بما فيها مجلد `.github/workflows`.
3. افتح تبويب Actions في المستودع.
4. اختر سير العمل `Build Noor Alhuda APK` ثم اضغط `Run workflow`.
5. بعد انتهاء البناء بنجاح، افتح نتيجة التشغيل ونزّل ملف `Noor-Alhuda-debug-apk` من قسم Artifacts.
6. فك ضغط الملف على الهاتف، ثم افتح APK للتثبيت إذا سمحت إعدادات أندرويد بذلك.

قد يستغرق البناء الأول وقتاً، ويتطلب اتصال إنترنت. لا ترفع كلمات مرور أو مفاتيح خاصة إلى المستودع.
